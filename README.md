# Facebook Clone Website

This project is a front-end clone of the Facebook website built using HTML and CSS. It recreates the look and layout of Facebook’s login page, including the logo, promotional section, and login form.

**Features**
- Facebook-inspired user interface
- Responsive layout for different screen sizes
- Custom styling using CSS
- Login page design

**Technologies Used**
- HTML5
- CSS3

**Purpose**

This project was created to practice front-end web development, improve CSS layout skills, and understand responsive website design.

**Note:** This is a learning project and is not affiliated with or endorsed by Facebook.
